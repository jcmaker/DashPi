# DashPi 앱 1.2.2

이미지 리포트에서 공유 버튼을 눌렀을 때 `Property 'crypto' doesn't exist` 오류가 발생하던 문제를 수정했습니다. 공유 파일 이름의 난수는 Android와 iOS에서 지원하는 Expo Crypto로 생성합니다.

- 이미지 리포트의 버튼을 **PDF 저장·공유**로 변경했습니다. 대표 사진 3장, 요약, 12개 확인 항목 전체, 타임라인, 분석 한계와 증거 정보를 A4 PDF로 만듭니다.
- Android 공유 메뉴의 **PDF 파일 저장**을 선택하면 시스템 파일 선택창에서 저장 위치를 고를 수 있습니다. PDF를 다른 앱으로 공유하는 기능도 제공합니다.
- PDF 생성·저장·공유를 취소하거나 실패해도 앱에 저장된 원본 JSON은 보존합니다. 공유 임시 파일은 선택한 앱 또는 파일 복사가 끝난 뒤 삭제합니다.
- 예전 HTML·영상 기록은 기존 파일 형식으로 공유합니다. 외부에서 수신한 HTML은 PDF 생성기로 실행하지 않습니다.
- Pi 1.2.0과 호환됩니다. 이미지 3장·60 KB 이하 전송은 유지하며 Pi 업데이트는 필요하지 않습니다.

검증: 네이티브 Node 테스트 74개, TypeScript, 변경 코드 ESLint, Android production export 통과. 브라우저 인쇄 엔진으로 생성한 일반 3쪽·장문 5쪽 PDF에서 한글, 사진 3장, 전체 항목과 증거 정보, 페이지 나눔을 확인했습니다. 브라우저 PDF 검증은 Android 실기 검증을 대신하지 않습니다. Android 기기가 연결되지 않아 실제 PDF 생성·저장 선택창·다른 앱 공유는 미검증입니다.
