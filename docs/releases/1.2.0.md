# DashPi 앱 1.2.0

LCD QR 전송에서 영상 대신 사고 전·순간·후 이미지 3장과 분석 결과를 보냅니다. 전송 JSON은 60 KB 이하로 만들며, 필요하면 이미지 품질과 해상도를 낮춥니다. QR 크기와 표시 속도는 그대로입니다. 실제 수신 시간은 휴대폰 카메라와 프레임 손실에 따라 달라집니다.

- 수신 후 사진과 시간별 관찰 문장이 연동되는 리포트가 바로 열립니다.
- 저장 목록에 사고 시각, 대표 이미지와 요약이 표시됩니다.
- 공유 또는 저장을 누르면 이미지가 포함된 HTML 파일을 만듭니다. 다른 기기에서도 인터넷 없이 열 수 있습니다.
- 예전 HTML 리포트도 계속 열립니다. Pi의 기존 기록은 이미지 전송으로 변환하고, 변환이 어려운 경우 기존 영상 포함 HTML 전송임을 안내합니다.
- 이미지가 손상된 경우 해당 이미지의 오류를 표시하고 원본 수신 파일은 보관합니다.

기존 서명된 APK 위에 업데이트할 수 있습니다. 앱을 먼저 1.2.0으로 업데이트한 뒤 Pi를 업데이트하세요. 구 앱은 새 JSON 리포트를 화면에 표시하지 못하고 원본 파일 저장·공유만 할 수 있습니다.

Pi의 원본 증거 영상과 기존 리포트는 유지합니다. 이미지 전송은 번호판 판독을 보장하지 않으며, 12개 항목 확인표는 법적 과실 판단이 아닙니다.
