# DashPi 앱 1.2.1

이미지 리포트 화면을 제공된 시안에 맞춰 새로 구성했습니다. 밝은 배경, 파란 선택 버튼, 요약 카드, 12개 항목 확인 카드, 사진과 연동되는 세로 타임라인을 적용했습니다.

- 사진 전·순간·후 전환과 전체화면 보기를 제공합니다.
- 12개 항목은 대표 항목과 전체 상세를 함께 볼 수 있습니다. 확인 불가 항목 수를 별도로 표시하며 법적 판단으로 단정하지 않습니다.
- 기존 확인표의 ‘관찰됨’ 항목만 관련 장면 태그로 표시합니다. 추가 AI 분석이나 위험도 추정은 하지 않습니다.
- 분석 한계와 원본 영상 미전송 안내를 유지하고, 공유 HTML에도 같은 색상과 내용 순서를 적용했습니다.
- 이미지 3장·60 KB 이하 전송, 수신 검증, 원본 보관과 구 HTML 호환성은 유지합니다.

앱 1.2.0에서 기존 서명으로 업데이트할 수 있습니다. Pi 1.2.0과 호환되며 이번 UI 변경 때문에 Pi를 다시 업데이트할 필요는 없습니다.

검증: 네이티브 Node 테스트 70개, TypeScript와 변경 코드 lint, Android production export 통과. 실제 화면 컴포넌트의 브라우저 미리보기에서 320px/390px, 확대 글자 모의 화면, 사진 전환·전체화면·확인표 펼침을 확인했습니다. Android 기기가 연결되지 않아 실제 네이티브 레이아웃·공유 시트는 미검증입니다.
