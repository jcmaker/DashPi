# PRD — DashPi

## Product Overview
DashPi is an offline-capable smart dashcam system that extracts accident footage and generates an AI-based summary immediately after an incident.

## Target Users
- Individual drivers

## Core Value
"Understand your accident instantly"

## Key Features (MVP)
- Loop recording
- Clip extraction (pre/post trigger)
- AI-based summary
- Mobile viewing (local connection)

## User Flow
1. Recording during driving
2. User triggers accident via app
3. Clip extraction
4. AI analysis
5. Result delivered to app

## Success Criteria
- Clip extraction works reliably
- AI summary is generated
- End-to-end demo works
